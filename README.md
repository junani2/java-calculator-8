# java-calculator-precourse

## 구현할 기능 목록 정리!

### ⭐️요구사항 분석
- **입력값** : 문자열
- **기본 구분자** : , 와 :
- **커스텀 구분자** : //[구분자] \n 
- **구하고자 하는 것** : 구분자를 제외한 숫자들의 합
- **예외처리**: 
    - 음수일 경우
    - 숫자가 아닐 경우
    - 잘못된 커스텀 구분자 입력의 경우 
  
     -> IllegalArgumentException 발생 !

---
### ⭐️기능 목록
1. 문자열을 입력 받는다.
2. 문자열이 비어있을 경우 0을 출력한다.
3. //로 시작할 경우 커스텀 구분자임을 판별한다. 아닐 경우엔 기본 구분자를 사용한다. 
4. 만약 커스텀 구분자에 잘못된 형태라면 IllegalArgumentException 발생시킨다. 
5. .구분자를 기준으로 문자열을 분리한다. 
6. 분리된 문자열을 숫자로 형변환을 한다. 
7. 음수가 존재하거나, 숫자가 아니라면 IllegalArgumentException 발생시킨다.
8.  각 숫자의 합을 더하여 결과를 출력한다. 


기본 구분자일 경우 , 나 : 만 제거해서 형변환 후 숫자만 추출  (replace)
커스텀 구분자일 경우 startsWith을 이용하여 시작이 //인지 그리고 \n의 위치 -1값으로 구분자값 찾기
    substring으로 \n 다음 위치부터 -1까지를 새로운 문자열로 담고 기본 구분자처럼 해결
